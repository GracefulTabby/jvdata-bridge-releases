# JVData Bridge

**競馬データを、AIと一緒に予想・分析できる環境へ。**

JVData Bridge は、JRA-VAN DataLab. の競馬データを PostgreSQL に取り込み、競馬予想・データ分析・AI連携のためのデータベースを構築する Windows アプリです。

連携MCPサーバー [**jvdata-bridge-mcp**](https://github.com/GracefulTabby/jvdata-bridge-mcp) と組み合わせると、対応するAIクライアントから出馬表・過去走・オッズ・調教などを参照し、会話形式で比較や分析を進められます。SQL・Python・BIツールなどからデータベースを直接利用することもできます。

## ダウンロード

[**Releases**](https://github.com/GracefulTabby/jvdata-bridge-releases/releases) の **Assets** からダウンロードしてください。

| 配布形式 | ファイル |
|---|---|
| **インストーラー版（推奨）** | `JVDataBridge-<version>-setup-win-x64.exe` |
| **ポータブル版** | `JVDataBridge-<version>-win-x64.zip` |

配布ファイルのSHA-256は、対応する `.sha256` ファイルに記載しています。起動時に「WindowsによってPCが保護されました」と表示された場合は、[SmartScreenの警告への対処](#windows-warning)をご確認ください。

## 主な特徴

### 🤖 AIと会話しながら予想・分析

MCPの専用ツールを通して、AIが取り込み済みの競馬データを参照します。たとえば、次のような質問から比較や分析を進められます。

- *「このレースの出走馬について、近走と調教内容を比較して」*
- *「このレースの単勝・複勝オッズを確認して」*

AI連携には、MCPサーバーのセットアップとAIクライアントへの接続設定が必要です。

### 📊 予想や分析に使いやすいデータ

固定長の配信データを、日付・数値などの型を持つテーブルとビューへ変換します。予測用出馬表とレース結果を分け、目的に応じたデータを参照できます。

| データ | 活用例 |
|---|---|
| **出馬表・過去走** | 出走馬の近走や、距離・コースごとの成績を比較する |
| **レース結果** | 着順・走破時計・上がり3Fを使ってレースを振り返る |
| **単勝・複勝オッズ推移** | 発表時刻ごとのオッズの変化を調べる |
| **馬体重・増減** | 当日の馬体重と前走からの変化を確認する |
| **坂路・ウッドチップ調教** | 各馬の調教時計を比較する |
| **レースラップ** | レース全体のペース配分を分析する |

### 📖 日本語で確認できるデータカタログ

テーブル・項目の意味やコード値の説明を日本語で確認できます。アプリ内でも項目定義やサンプルデータを調べられるため、SQLや分析に必要なデータを探せます。

### 🖥️ GUIでかんたん設定・定期同期

画面の案内に沿ってデータベースを設定し、「自動実行」をONにすると、通常データと当日の速報データを定期取得します。取得間隔の初期値は通常15分・速報60秒で、設定から変更できます。画面を閉じても取り込み処理はバックグラウンドで継続します。

アプリの起動時には、本体の更新も確認します。インストーラー版は **「設定」→「アプリ更新」** から更新ファイルをダウンロードし、インストーラーで適用できます。ポータブル版は配布ページから新しいZIPを取得して更新します。

## 必要環境

- **OS**：64-bit Windows 10（1809 以降）または Windows 11
- **JRA-VAN**：利用者ご自身の有効な JRA-VAN DataLab. 利用権
- **JV-Link**：公式JV-Linkの **32bit版** のインストールと利用キーの設定
- **データベース**：PostgreSQL 18（推奨）

64-bit Windows 上でも、JV-Linkは32bit版を使用してください。JVData Bridge用の.NETランタイムを別途インストールする必要はありません。

## 使い始めるには

1. **インストールして起動する**
   必要環境を準備し、インストーラーを実行して、スタートメニューから **JVData Bridge** を起動します。ポータブル版はZIPを展開し、同梱の `README.md` と同じフォルダーを基準に `app/desktop/jvdata-desktop.exe` を起動します。
2. **データベースを設定する**
   初期セットアップ画面で **「データベースを作成」** を選びます。PostgreSQLの接続先・管理者情報を入力し、**「管理者として接続を確認」** → **「データベースを作成」** の順に進みます。設定後は **「診断」** 画面で接続状態を確認してください。
3. **データを取り込む**
   **「データ取り込み」** 画面の **「自動実行」** をONにします。取り込みの進捗・履歴と、**「データ状況」** 画面のDB反映状態を確認してください。
4. **AIや分析ツールに接続する**
   **「設定」→「外部接続ユーザー」** で接続ユーザーを確認します。AI連携は [MCPサーバーの導入・接続手順](https://github.com/GracefulTabby/jvdata-bridge-mcp#readme)に沿って設定してください。

初回は過去データの取得とDBへの反映が必要です。分析に使えるようになるまでの時間は、取得期間・データ量・PC環境によって異なります。

PCを再起動した後は、JVData Bridgeを起動してください。保存済みの自動実行設定に従って同期が再開します。詳しい操作方法とトラブル対応は、配布物に同梱された `README.md` を参照してください。

## Windows SmartScreenの警告が表示された場合

インストーラーやアプリの起動時に、Microsoft Defender SmartScreenの **「WindowsによってPCが保護されました」** という警告が表示される場合があります。

1. [本リポジトリのReleases](https://github.com/GracefulTabby/jvdata-bridge-releases/releases)からダウンロードしたファイルであることと、画面に表示されたファイル名を確認してください。
2. 確認したファイルを実行する場合は、**「詳細情報」→「実行」** を選びます。

「実行」が表示されない場合や別のセキュリティ機能でブロックされた場合は、画面のメッセージを添えて[Issues](https://github.com/GracefulTabby/jvdata-bridge-releases/issues)へお知らせください。ウイルス対策ソフトが脅威を検出した場合は実行を中止してください。
