# JVData Bridge

**JVData Bridge** は、JRA-VAN DataLab. の競馬データを、人間にも AI にも扱いやすい **PostgreSQL データベース** へ高速に同期する Windows アプリです。

公式 JV-Link から取得した競馬データを、使いやすいデータベースへ自動変換して保存。
公式連携 MCP サーバー [**jvdata-bridge-mcp**](https://github.com/GracefulTabby/jvdata-bridge-mcp) を使えば、**セットアップしたその日から ChatGPT や Claude、Cursor などの AI に競馬データを直接接続して、予想やデータ分析を始めることができます。**

## 主な特徴

### 1. 🤖 導入したその日から、AI で競馬予想・データ分析
公式連携 MCP サーバー [**jvdata-bridge-mcp**](https://github.com/GracefulTabby/jvdata-bridge-mcp) に対応。
ChatGPT や Claude、Cursor などの AI に接続するだけで、AI が専用の競馬ツールを使ってデータを自動で取得し、普段の会話で予想や分析をしてくれます。

- *「今週末のメインレースの出馬表を出して、有力馬を分析して」*
- *「過去走と調教タイムから、調子の良さそうな穴馬を教えて」*
- *「過去5年で、雨の日の芝2000mにおいて勝率の高い枠番・脚質を分析して」*

### 2. 📊 人間にも AI にも優しい、整理されたデータベース
JRA-VAN 公式の難しいデータを、すぐに使える綺麗なテーブルに自動変換します。
- **安心の予測用出馬表**: レース前の出馬表データには結果情報が含まれないため、AI の予想でも安心。
- **全項目に日本語の解説つき**: すべてのテーブル・項目に分かりやすい日本語の説明がついているため、人間が見ても AI が見ても迷いません。
- **欲しいデータが勢揃い**: 出馬表、レース結果、各馬の過去走、オッズ推移、馬体重、調教タイム、レースラップなど、競馬ファンが欲しいデータを網羅。

### 3. ⚡ 高速同期 & スイッチひとつの「自動実行」
- **マウスだけの簡単操作**: 面倒な設定は不要。見やすいデスクトップ画面からワンクリックで操作できます。
- **「自動実行」スイッチを ON にするだけ**: 通常データはもちろん、レース当日のリアルタイムオッズや馬体重などの速報データも自動で巡回取得します。
- **画面を閉じても安心**: 取り込みはバックグラウンドで安全に継続されます。

## 利用に必要な環境

- **OS**: 64-bit Windows 10 または Windows 11
- **JRA-VAN**: JRA-VAN DataLab. の利用権 と **公式 JV-Link** のインストール
- **データベース**: **PostgreSQL 18**（推奨）
- **空き容量**: 数年分のデータを保存する場合、数十GB程度の空き容量を推奨

> ※ 追加のランタイム等のインストールは不要です。

---

## かんたん3ステップで開始

1. **アプリを起動**: インストールした `JVData Bridge` を起動します。
2. **初期セットアップ**: 画面の案内に沿って PostgreSQL の管理者パスワードを入力すると、専用データベースが自動で作成されます。
3. **取り込み開始**: 「データ取り込み」画面の **「自動実行」スイッチを ON** にするだけで、データの同期が始まります。

※ AI（ChatGPT や Claude 等）と接続する手順は、[**jvdata-bridge-mcp**](https://github.com/GracefulTabby/jvdata-bridge-mcp) のマニュアルをご覧ください。
